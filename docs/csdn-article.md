## 1、它是个什么东西

BiliFetch 是一个跨平台的 B 站视频下载工具，同时提供图形界面和命令行两种用法，走的是同一套下载逻辑，所以两边行为完全一致。界面用 PyQt5 写的，打包成 `.app` 之后**用户的机器上不需要装 Python**，拖进去双击就能开；Linux 那边提供 `.deb`，图形界面依赖系统的 `python3-pyqt5`。

它能处理的内容范围比较全：普通视频、番剧正片、分 P、合集、收藏夹，还有 `b23.tv` 那种短链，粘进去都能识别。下载方式是分片并发拉取，会自动挑当前最快的 CDN 镜像，实测能跑满家里的带宽；中途断网或者手动停了，下次打开会从断点继续，不用从头再来。

## 2、怎么装

macOS 上最省事：下载 `BiliFetch-1.0.0-macOS.dmg`，打开之后把 `BiliFetch.app` 拖到右边的 **Applications** 图标上就可以了。拖完在「应用程序」里就能看到那只小狐狸，双击即用。

第一次双击如果提示「无法验证开发者」，**右键点 BiliFetch.app → 打开 → 再点「打开」**就行。这是个人项目没做公证（notarization）造成的，不是文件坏了。

Linux 用 `sudo apt install ./bilifetch_1.0.0_all.deb` 装完，再补上 `python3-pyqt5` 和 `ffmpeg`（合并音视频要用）即可。喜欢命令行的话，`bilifetch 'https://www.bilibili.com/bangumi/play/ep1633643'` 一条链接直接开下，和图形界面共用同一套逻辑。

## 3、怎么用（三步）

第一步，把 B 站链接粘到输入框，点「浏览…」；第二步，软件会把链接里的内容列成一份清单，你勾哪些它下哪些；番剧会把整季都列出来，花絮、PV、二创这些默认折叠，需要的话自己勾上。

![浏览预览](https://raw.githubusercontent.com/oldsixxiaolv/bilifetch/main/docs/screenshot-collection.png)

第三步，点「确认下载」，下面就是队列，能看到每一集的进度、速度和状态，想停随时点「停止」，不需要了可以「清空」重来。文件默认存在 `~/Downloads/BiliFetch`，点右下角「打开输出目录」直接去看。

![下载中](https://raw.githubusercontent.com/oldsixxiaolv/bilifetch/main/docs/screenshot-empty.png)

## 4、扫码登录拿 1080P 和 4K

不登录的时候 B 站只给 480P，这是平台的限制，不是软件的。右上角点「扫码登录」，用手机 B 站 App 扫一下二维码、手机上确认一下，就解锁了 1080P 及以上（大会员的话还有 4K 和杜比）。

![扫码登录](https://raw.githubusercontent.com/oldsixxiaolv/bilifetch/main/docs/screenshot-login.png)

二维码有效期 180 秒，过期了点「刷新二维码」换一张就行。登录状态是存在本机的，**下次打开直接就是已登录**，不用重复扫码；只有你自己点了右上角的「退出登录」才会清掉。

## 5、几个用起来比较顺手的地方

**下载途中能随时打断。** 点「停止」后台会立刻掐断正在下的连接，不是干等着当前这一集下完——按下去一两秒内队列就空了，接着可以重新开始或者直接清空。

**只要声音不要画面。** 在浏览窗口里勾「只下音频」，出来的就是纯音频文件。

**断点续传。** 分片下载，每 4MB 一片下完就记一次进度。中途断了、换网了、或者电脑睡醒了，重新打开接着下。

**下载速度。** 16 路并发 + 自动挑最快镜像，音视频两条流并行拉。实测 1080P 的番剧稳定在 15MB/s 上下，4K 会慢一些，取决于你的带宽。

**不经过第三方。** 所有请求都是直连 B 站和它的 CDN，没有中间服务器，你的链接和账号只发往 B 站本身。

## 6、需要注意的几个点

**没做公证**，macOS 第一次打开会拦一下，按上面说的右键打开就能过。

**番剧的 DRM 加密内容下不了**，这是格式本身的限制，目前没有能可靠绕过的办法。

**个别清晰度需要大会员**，普通账号最高 1080P。

**仅供学习研究**，请遵守 B 站的用户协议，不要拿它做批量搬运或者离线盗版这类用途。
